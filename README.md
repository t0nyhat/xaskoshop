# ХаскоШоп — статический MVP

Главная страница: `index.html`. Её можно открыть двойным кликом — сервер и интернет для загрузки интерфейса не нужны.

Опубликованная версия: <https://t0nyhat.github.io/xaskoshop/>

Все рабочие ресурсы находятся локально:

- `assets/css/styles.css` — собранные стили;
- `assets/css/catalog.css` — адаптивная сетка каталога и подробный просмотр товара;
- `assets/fonts/` — локальные шрифты;
- `assets/images/lifestyle/` — фотографии разделов;
- `assets/images/products/` — фотографии упаковок.
- `assets/images/brand/logo-mark.jpg` — компактный фирменный знак для шапки и favicon;
- `assets/images/brand/logo-full.jpg` — полный фирменный логотип в контактах и для превью ссылки.

Контакты, адрес, ссылки на мессенджеры и режим отображения цен меняются в объекте `CONFIG` в начале JavaScript внутри HTML.

Карточки каталога показывают фото, название, тип корма, белок и жир, фасовки, наличие, цену и кнопку «В корзину». Если выбранной фасовки нет на складе, кнопка меняется на «Предзаказ», а фасовка отмечается точкой. После нажатия кнопка на секунду показывает «Добавлено». На экранах уже 600 px фото занимает левую часть карточки на всю высоту, а справа идут название, показатели, гранула, фасовки, цена с наличием и кнопка. Подробности открываются нажатием на фото или название.

Полный состав, описание, хранение и таблица кормления открываются по нажатию на фото, название или «Состав». В подробностях фото занимает всю левую колонку и остаётся на месте при прокрутке, справа — описание, выбор фасовки, наличие, цена и характеристики. Фото открывается крупно по нажатию. На телефоне подробности занимают весь экран; закрыть их можно кнопкой или клавишей Escape. Выбранная фасовка сохраняется при переходе между каталогом и подробностями.

### Наличие

Сейчас наличие тестовое: остаток рассчитывается из id товара и фасовки, примерно треть фасовок получается «под заказ», и при каждом заходе результат одинаковый. Чтобы показывать настоящие остатки, подключите перед основным скриптом файл с `window.XS_STOCK = { 'id товара|гранула|фасовка': количество }`, например `{'acari-regular|S|1 кг': 4}`. Фасовки, которых нет в этом объекте, считаются отсутствующими.

Если меняются Tailwind-классы, CSS пересобирается командой:

```sh
npm_config_cache=/tmp/xaskoshop-npm-cache npx --yes tailwindcss@3.4.17 -c tailwind.config.cjs -i assets/css/input.css -o assets/css/styles.css --minify
```

Источники изображений и важная правовая оговорка указаны в `assets/IMAGE_SOURCES.md`.

## Каталог ACARI CIAR

Актуальный каталог марки хранится в `assets/data/acari-products.js` и подключается к витрине автоматически. В него входят карточки для собак и кошек, фасовки, описания, составы, питательные показатели, фотографии упаковок и опубликованные производителем таблицы кормления. Названия с сайта производителя (например, «А `КЭТ», «ВЕТ/ А`ДОГ») витрина при показе приводит к одному виду: «А’Кэт», «Вет А’Дог».

Для повторного чтения официального каталога и обновления локальных материалов:

```sh
python3 -m pip install lxml Pillow
python3 scripts/sync_acari.py
```

Результат проверки записывается в `assets/data/acari-sync-report.json`, полный структурированный набор — в `assets/data/acari-catalog.json`. Фотографии упаковок сохраняются в WebP с длинной стороной не больше 800 px — так каждая весит десятки килобайт вместо мегабайта. Таблицы кормления остаются в исходном формате, чтобы цифры читались.

### Цены по оптовым прайсам

Фасовки, гранулы и розничные цены берутся из оптовых прайсов в папке `opt_price/` (она не попадает в репозиторий). После замены прайсов или синхронизации каталога:

```sh
python3 -m pip install xlrd openpyxl
python3 scripts/apply_prices.py
```

Скрипт читает листы «от 1000» и «КОНС ОПТ» и записывает в `assets/data/acari-prices.js` только розничные цены. Там же оказываются товары из прайса, которых нет на сайте производителя. Розница — это опт плюс наценка, зависящая от веса упаковки; цена округляется вверх. Наценки задаются в `opt_price/markup.json` и в репозиторий не попадают. Подробный отчёт с оптовыми ценами сохраняется в `opt_price/apply-report.txt`.

Если в прайсе цена зависит от размера гранулы, в карточке появляется выбор «Гранула для мелких / средних / крупных / декоративных». Товары, которых нет в прайсе, остаются с пометкой «цена по запросу».

## Корзина и заказ

Корзина хранится в браузере. Оформление идёт в два шага: сначала список товаров с количеством, наличием и итогом, затем контакты (имя, телефон, комментарий) и отправка заказа. Позиции, которых нет на складе, помечаются как предзаказ. Если заказано больше, чем есть, в заказе указывается, сколько штук в наличии и сколько под заказ. Заказ уходит сообщением в мессенджер и не резервирует товары автоматически.

Telegram открывается с подготовленным текстом. Для MAX сначала показывается и копируется текст, затем пользователь открывает чат через `CONFIG.maxUrl`, вставляет сообщение и отправляет его. Если доступ к буферу запрещён, текст можно выделить и скопировать вручную. Ссылку на профиль магазина нужно поддерживать актуальной в `CONFIG`.
